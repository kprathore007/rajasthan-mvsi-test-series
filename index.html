Add or Import Question Bank

Supports your uploaded JSON fields: question_en, A_en–D_en, correct, explanation_en, and section. Existing question-bank data is not overwritten unless you confirm a replacement.

Supported JSON example
[{"section":"Automobile Chassis and Drivetrain","question_en":"What is the primary function of a differential?","A_en":"Increase engine speed","B_en":"Allow drive wheels to rotate at different speeds","C_en":"Cool the gearbox","D_en":"Operate the 
brakes","correct":"B","explanation_en":"A differential allows the drive wheels to rotate at different speeds while cornering."}]

Generate a Mock Online

Creates a draft using web-sourced PYQ candidates and/or new AI practice questions. Questions are not saved until you review and approve them. Internet access is required to generate; saved questions can then be practised offline.

Important: A source link alone does not prove that the exact question or its answer key has been verified. Check the source, answer and explanation for every question before approving it. AI-generated questions also require review.

Connect your secure generator

Paste the public URL of your deployed Cloudflare Worker (not your OpenAI API key). The API key must stay in Cloudflare Worker Secrets.
